# Intel Three-Statement Financial Model

I wanted to build a professional version of a financial model that I was
curious to learn more about. I wanted to build one from scratch and pull 
the data from the 10-k's. In addition, used what I built to forecast future 
financial projections. 

# Status

I broke this project into 4 segments: lite, core, full, and pro. 
The first three stages are completed, and I am halfway done with the 
pro version. 

# What's in the model

- Summary
- Assumptions
- Income Statement
- Balance Sheet
- Cash Flow Statement
- Scenarios
- Payback
- PP&E Schedule
- Working Capital
- Debt Schedule
- Credit Ratios
- Sensitivity
- DCF
- Comps
- Valuation Summary
- Checks
- Share Count Notes 


## Data sources

- [FY2025 Form 10-K](https://www.sec.gov/ix?doc=/Archives/edgar/data/0000050863/000005086326000011/intc-20251227.htm)
- [FY2024 Form 10-K](https://www.sec.gov/ix?doc=/Archives/edgar/data/0000050863/000005086325000009/intc-20241228.htm)

## Limitations

Public filings only; no internal company data,
simplified in places.
